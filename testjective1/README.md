# EduPilot AI

EduPilot AI — веб-приложение с ИИ-помощником для учителей и учеников. Оно помогает готовить уроки, создавать тесты, анализировать успеваемость, выявлять пробелы в знаниях и составлять адаптивные занятия.

Слоган: **«ИИ-помощник учителя: планирует, оценивает, анализирует и адаптирует»**.

## Текущее состояние проекта

В репозитории реализована демоверсия на React, TypeScript, TanStack Start и Tailwind CSS. Данные находятся в `src/lib/data.ts`, имитация работы ИИ — в `src/services/aiAgent.ts`. Подключения к Supabase и OpenAI пока нет. Форма входа переключает страницы без настоящей аутентификации; изменения демоданных не сохраняются на сервере.

Готовые страницы: главная, вход, кабинет учителя, список и обзор классов, список и профиль учеников, генераторы уроков и тестов. В интерфейсе есть ссылки на `/app/agent`, `/app/analytics`, `/app/settings`, `/app/assessments/results` и `/quiz`, но соответствующие страницы пока отсутствуют. Часть действий лишь имитируется или ещё не реализована.

Ниже приведено техническое задание на целевой продукт. Оно описывает также возможности, которые предстоит реализовать.

## Назначение и технологии

Создать современное приложение в стиле образовательного SaaS. Это не просто чат: интерфейс должен наглядно показывать, как ИИ-агент анализирует данные класса и выбирает следующий шаг обучения.

Целевой стек: React, TypeScript, Tailwind CSS, Supabase для базы данных и аутентификации, при необходимости Supabase Storage для файлов. Использовать понятную компонентную архитектуру и адаптивный дизайн с приоритетом настольных экранов.

До подключения настоящего ИИ использовать реалистичные имитации ответов. Архитектуру подготовить к последующему подключению OpenAI API.

## Пользователи и вход

## Профиль ученика

Показать имя, общий уровень освоения и диаграмму навыков. Пример: переменные — 90%, условия — 82%, циклы — 54%, `range()` — 31%, вложенные циклы — 20%.

Добавить последние ошибки, типичное заблуждение и рекомендации. Пример рекомендации ИИ: «Аружан пока не понимает, что `range(5)` в Python начинается с 0 и не включает 5».

Кнопки: «Создать практику», «Создать индивидуальный учебный план», «История тестов».

## Страница ИИ-агента

Одна из ключевых страниц. Интерфейс напоминает чат, но должен явно показывать работу агента, выполняющего несколько задач.

Заголовок: «ИИ-помощник учителя». Подзаголовок: «Анализирует данные класса и выбирает следующий шаг обучения».

Пример запроса: «Подготовь завтрашний урок на основе сегодняшнего теста».

После отправки показать анимированное выполнение этапов:

1. Анализ успеваемости класса.
2. Выявление пробелов в знаниях.
3. Изучение целей учебной программы.
4. Создание структуры урока.
5. Создание заданий разного уровня.
6. Создание итогового теста.

Для завершённых этапов показывать статус «Завершено». Итог: «Урок готов».

Резюме ИИ: «Я проанализировал последний тест. 14 из 25 учеников испытывают трудности с `range()`. Рекомендую повторить `range()` перед изучением вложенных циклов».

Кнопки: «Открыть урок», «Создать рабочий лист», «Создать тест», «Изменить план».

## Генератор уроков

Страница «Создать урок». Поля: класс, параллель, предмет, тема, продолжительность, сложность, учебная цель.

Пример: класс 8А, параллель 8, информатика, тема «Циклы for в Python», 45 минут. Кнопка «Создать урок с ИИ» запускает отображение этапов работы агента.

Готовый урок содержит название, учебную цель, продолжительность, необходимые материалы и структуру:

| Время | Этап |
| --- | --- |
| 0–5 мин | Разминка |
| 5–12 мин | Объяснение понятия |
| 12–20 мин | Демонстрация кода учителем |
| 20–32 мин | Практика учеников |
| 32–40 мин | Задание повышенной сложности |
| 40–45 мин | Итоговый тест |

Кнопки: «Редактировать урок», «Создать заново», «Создать упражнения», «Создать тест», «Экспорт».

## Задания разного уровня

Создать три раздела: начальный, средний и продвинутый. Учитель может заново создавать задания каждого уровня независимо.

Начальный уровень: «Какие числа выведет этот код?»

```python
for i in range(5):
    print(i)
```

Средний уровень: «Напишите программу, которая выводит числа от 1 до 10 с помощью цикла for».

Продвинутый уровень: «Напишите программу, которая вычисляет сумму чисел от 1 до N с помощью цикла for».

## Генератор тестов

Страница «Создать тест». Поля: класс, тема, количество вопросов, сложность, типы вопросов.

Типы: выбор ответа, краткий ответ, задание на код, верно / неверно. Кнопка «Создать тест» формирует пример теста по циклам Python.

Пример: «Какие значения создаёт `range(3)`?»

- A: `1,2,3`.
- B: `0,1,2`.
- C: `0,1,2,3`.

Правильный ответ: **B**. Учитель может редактировать, удалять и заново создавать вопросы, добавлять новые и публиковать тест.

## Тест для ученика

Простой интерфейс: «Сегодняшний тест», тема «Циклы Python», «Вопрос 1 из 5».

Вопрос: «Что выведет следующий код?»

```python
for i in range(3):
    print(i)
```

Варианты: `1 2 3`, `0 1 2`, `0 1 2 3`. Кнопка «Отправить ответ».

Сразу после ответа показать обратную связь. При ошибке: «Не совсем. Возможно, вы думаете, что `range(3)` начинается с 1. В Python отсчёт начинается с 0».

Указать понятие `range()` и добавить кнопку «Попробовать похожий вопрос».

## Анализ результатов теста

## Дизайн и анимации

Стиль: современный образовательный SaaS, чистый, профессиональный, минималистичный, с акцентом на ИИ. Использовать большие белые карточки, лёгкие тени, скругления, современные диаграммы, понятную типографику и мягкие градиенты.

Основная палитра: белый или светло-серый фон, тёмный текст, синие либо индиговые акценты ИИ. Избегать мультяшного оформления. Предусмотреть адаптивную вёрстку, пустые состояния, загрузку, наведение и скелетоны.

Во время работы ИИ показывать общую для всего приложения вертикальную шкалу выполнения. Пример: анализ данных класса — ✓, выявление пробелов — ✓, проверка программы — ✓, создание урока — «Загрузка...», создание теста — «Ожидание».

## Главный принцип продукта

Не превращать продукт в простой клон ChatGPT. Ценность должна быть видна через работу учителя, данные учеников, аналитику, действия агента, адаптивные уроки и автоматические рекомендации.

Наглядно показывать цикл: **планирование → обучение → оценка → анализ → адаптация → повторение**.

## Главная страница

Заголовок: «Ваш ИИ-помощник учителя».

## Приоритеты реализации

При ограниченном времени соблюдать порядок: кабинет учителя, аналитика класса, процесс работы ИИ-агента, генератор уроков, результаты тестов, тест ученика, профиль ученика, аутентификация, настройки.

Первые пять возможностей должны быть тщательно оформлены и работоспособны. Вся навигация должна работать. Если действие можно имитировать, не оставлять кнопку без реакции. Без серверной интеграции использовать реалистичные процессы и результаты генерации.
